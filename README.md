# GTM

Go-To-Market 工具集 — 用于规范化 Notion 文档写作和 GTM 工作流的 AI Skills。

## Skills

### notion-write-skill.md

Notion 文档写作规范，供 Claude Code 等 AI 工具在创建/编辑 Notion 页面时自动加载，确保：

- 页面结构一致（callout 摘要 → 分隔符 → 大标题 → toggle 子板块）
- Callout 颜色体系统一（blue/green/yellow/red/orange/purple/gray 各有用途）
- 强调方式、表格、Columns 布局、语言风格保持一致
- 方案类文档聚焦策略层，不过度展开实现细节
